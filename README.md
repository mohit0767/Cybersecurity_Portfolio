# Google Cybersecurity Professional Certificate Portfolio 🛡️

Welcome to my cybersecurity portfolio! This repository tracks my journey, hands-on labs, and major deliverables completed during the Google Cybersecurity Professional Certificate program. 

The goal of this project is to document practical skills in network security, log analysis (SIEM), system hardening, and defensive automation.
